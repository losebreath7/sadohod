# Автоматические категории и поисковые признаки — этап 1

## Что изменено
Одна основная категория товара остаётся в `product_category_assignments` — старые
клиенты, фильтры каталога и рекомендации продолжают использовать её. Скрытые
поисковые признаки добавляются в `product_search_tags`. Это не дублирующиеся
карточки и не произвольно созданные разделы каталога.

Пример при уверенном распознавании фото:
- категория: `Игрушки → Детские игрушки → Мягкие игрушки`;
- признак: `обезьяна`;
- поисковые синонимы: `мартышка`, `обезяна`, `обезьянка`;
- сохраняются оригинальные фотография, заголовок, цена и продавец.

Распознавание категории, подпись на изображении и сортировка результатов —
разные задачи. «Обезьяна» здесь поисковый признак, а не самостоятельная
категория. Больше тегов **не гарантирует** нахождение произвольной картинки:
низкая уверенность или отсутствие ML-модели даёт пустое предположение,
но не скрывает опубликованный товар и не придумывает категорию.

## Как обновляются данные
- Alembic `20261120_11` добавляет только таблицу `product_search_tags`.
- При старте сервера пересчитываются не-ручные категории и признаки,
  включая опубликованные товары. В режиме OpenCLIP сначала индексируются
  фотографии, затем происходит классификация.
- Ручные категории не перезаписываются. Публикации, цены, статусы и адреса
  павильонов не меняются. Повторный запуск идемпотентен.
- Поиск по `/api/v1/search/text?q=` и `/api/v1/products?q=` использует
  и прежние названия, и точные нормализованные признаки.
- Отображаемый `search_tags` в JSON товара помогает проверять результаты
  без вмешательства в данные продавца.

## Проверка качества реальных фотографий
Тесты с подставными голосами модели проверяют интеграцию и защиту данных,
**не точность OpenCLIP на фотографиях**. Для реального измерения подготовить
JSON-файл из размеченных товарных фото. Минимально полезный набор —
обезьяны, зайцы, кольца, юбки, коврики, светильники, аксессуары, а также
негативные примеры: футболка с принтом обезьяны, брелок-обезьяна,
чехол с изображением кольца. Нужны реальные снимки нескольких продавцов
с разными ракурсами, освещением и фоном.

Пример `server/labels.json`:
```json
[
  {"image": "photos/monkey.jpg", "leaf": "toys-plush", "object": "обезьяна"},
  {"image": "photos/ring.jpg", "leaf": "jewelry-rings"},
  {"image": "photos/skirt.jpg", "leaf": "clothing-skirts"}
]
```
Запуск из `server/`, в окружении со скачанными весами OpenCLIP:
```bash
python -m backend.tools.evaluate_category_labels labels.json
```
Сравниваются coverage, precision_when_assigned, leaf_accuracy и качество
объектных признаков. Не настраивать пороги на нескольких демонстрационных
картинках и не заявлять подтверждённой точности до теста на независимой
выборке. В случае ошибок корректировать словарь классов, пороги и правила
отказа, сохраняя ручную категорию приоритетной.
