# Первый перенос R8 в GitHub

Источник: **SADOHOD_WINDOWS_2026-11-16_R8_CHAT_POLISH_BUILD27_WITH_GATE**.

Импорт выполняется **один раз**, из распакованной папки `SADOHOD` с `tools/release_files.txt`.

1. Установить Git for Windows или GitHub Desktop, войти в аккаунт `losebreath7`.
2. Скачать вспомогательный файл `ПЕРЕНЕСТИ_САДОХОД_В_GITHUB.bat` из диалога ChatGPT и поместить его **рядом с** `ВОРОТА.bat`.
3. Двойным кликом запустить перенос. Команда создаст соседнюю папку `SADOHOD_GIT` и клонирует приватный репозиторий на ветке `develop`.
4. Из исходного R8 берутся только файлы из `tools/release_files.txt`. Рабочие `.env`, базы, резервные копии, лог-файлы, пользовательские фотографии и прочие рабочие данные не копируются.
5. `server/backend/media/products/` исключается, кроме 12 фиксированных картинок `p01.jpg`—`p12.jpg` из штатного `seed_demo`.
6. Скрипт проверяет распространённые форматы секретов перед коммитом, пересобирает список `release_files.txt` для импортированной версии и отправляет коммит в `develop`.
7. После push начнутся CI-проверки `gate` для `develop`. `main` останется незатронутой.

При ошибке авторизации можно открыть созданную `SADOHOD_GIT` через GitHub Desktop и выполнить **Push origin**. Не удалять старую рабочую папку и Docker Volumes.

После успешного импорта: дальнейшие изменения делать через ветки `fix/*` или `feature/*` и pull request. Временные ZIP-патчи больше не нужны.
