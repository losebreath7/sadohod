# R3: исправление замечания №6 — вложения чатов

Основа: SADOHOD_WINDOWS_2026-11-15_R2.zip.

В чатах покупателя и продавца сведения о вложениях и готовые миниатюры
теперь выбираются одним SQL-запросом на видимую страницу переписки
(последние 100 сообщений). Поле raw не входит в SELECT. Для пустой
переписки покупателя запрос вложений вообще не выполняется.

Формат ответа API сохранён: id, filename, mime, preview. Полный файл
по-прежнему выдаёт отдельный защищённый запрос скачивания. Отправка файлов
в Telegram также продолжает читать содержимое для доставки — это отдельная
операция, не загрузка переписки. Запрос метаданных ограничен владельцем
и идентификаторами сообщений текущей страницы.

Изменены backend/app/buyer_extras.py и backend/app/merchant_chat.py.
Добавлен backend/tests/test_chat_attachment_batch.py: 9 проверок для двух
ролей, двух каналов, короткой и длинной истории, пустой переписки,
сохранения миниатюр, скачивания и изоляции пользователей. SQL-перехватчик
проверяет количество запросов и отсутствие raw в выборке истории.

- Проверки чатов и Telegram: 25 passed.
- Полный серверный набор: 104 passed, 2 skipped.
