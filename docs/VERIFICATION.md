## Актуальный результат R4

111 серверных тестов прошли на SQLite, 3 PostgreSQL-теста пропущены.
Проверены миграции новой базы и копии заполненной прежней схемы.
PostgreSQL, Docker и Windows в этой среде не проверены; подробности —
[MIGRATIONS_R4.md](MIGRATIONS_R4.md). Ниже сохранены результаты прежних редакций.

На этапе упаковки проверены CRC ZIP, совпадение состава с перечнем поставки, SHA-256 файлов, пути COPY в обоих Dockerfile и синтаксис Python. Манифест описывает текущий ZIP. Секрет установки, кэши и предыдущий скомпилированный веб-клиент исключены.

В исходном отчёте предыдущей сборки зафиксировано 88 пройденных серверных тестов на SQLite. В этой сборке они повторно не запускались. Первый запуск и обновление написаны для Windows PowerShell 5.1 и Docker Desktop. Выполнение этих сценариев, восстановление на PostgreSQL и открытие клиентских окон Flutter в Windows остаются приёмочными проверками.

В следующей редакции добавлены ограничения фотопоиска, конфигурация доверенного Caddy и атомарное подтверждение почты. В среде сборки пройдены пять HTTP-проверок чтения multipart через FastAPI, проверена обработка доверенного и прямого соединений в Uvicorn. Прогон всей SQLite-серии, PostgreSQL, Caddy и Windows остаётся за изолированным стендом. Для SQL-проверок включён отдельный Compose-сценарий.
