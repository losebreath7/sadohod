# Рабочая панель модерации Садохода

Новая веб-панель не заменяет Flutter покупателя/продавца, действующую админку каталога или Telegram-мост. Она работает на **том же FastAPI, PostgreSQL и Docker Compose-проекте**.

## Открыть на Windows

Когда сервер обновлён из `develop` и запущен:

- Двойной клик по **ОТКРЫТЬ МОДЕРАЦИЮ.bat** → http://localhost:8000/preview/moderation.html
- Двойной клик по **УПРАВЛЕНИЕ МОДЕРАТОРАМИ.bat** → http://localhost:8000/preview/moderation-team.html

Папка проекта: `SADOHOD_GIT`. Если сервер остановлен, сначала запустите его обычным способом. Эти два ярлыка **не** обновляют базу и не создают контейнеры.

## Первое включение команды

1. Откройте **УПРАВЛЕНИЕ МОДЕРАТОРАМИ.bat**.
2. Введите *главный код администратора*. При обычной локальной установке его можно прочитать в PowerShell **на своём компьютере**, из каталога проекта:
   ```powershell
   docker compose exec -T api cat /app/state/admin-token.txt
   ```
   Если настроен `ADMIN_TOKEN`, используйте заданный вами код вместо файла.
3. Нажмите «Создать доступ», укажите логин сотрудника и его имя. Скопируйте **одноразовый пароль**, который покажет сервер: повторно тот же пароль не выдаётся.
4. Сотрудник открывает **ОТКРЫТЬ МОДЕРАЦИЮ.bat** и входит со своим логином и паролем.
5. Главный администратор может выключить доступ или сгенерировать новый пароль. Старые сессии сбрасываются.

**Никогда не присылайте главный код и пароли в ChatGPT, GitHub, скриншотах и общих Telegram-чатах.** Логин модератора не даёт доступ к API `/api/v1/admin/*`.

## Работа с заявками

В панели доступны продавцы, павильоны, товары, предложения (размещения в павильонах), новые отзывы, жалобы на отзывы и история действий. В карточке есть сведения для проверки и, где применимо, фотографии.

Одобрение/отклонение проходит через существующий серверный механизм с проверками дублей павильонов, фото, категорий и доступных предложений. Причина отклонения обязательна. Все решения модераторов сохраняются с ID задачи, автором, временем и комментарием.

Новые и отредактированные отзывы **не публикуются до подтверждения модератором**. Старые опубликованные отзывы остаются одобренными после миграции. Покупатель видит статус собственного отзыва и подтверждение отправки на модерацию.

Отдельный раздел «Обращения» показывает переписку для ориентации, но отправка ответов пока остаётся в менеджерской Telegram-группе. Двусторонний ответ через веб-панель потребует отдельного механизма синхронизации; в этой версии он намеренно не имитируется.

## Безопасность и совместимость

- Пароли хранятся только в виде PBKDF2-хэшей с индивидуальной солью; токены сессий — только в виде SHA-256-хэшей, срок 8 часов.
- Каждая операция модерации требует активной сессии сотрудника, которую можно немедленно отозвать.
- Проект использует текущие PostgreSQL Volumes. Миграция **аддитивная**, новые таблицы и поля не удаляют существующие данные.
- Перед обновлением рабочей установки используйте существующий безопасный скрипт `ОБНОВИТЬ САДОХОД.bat` с резервным копированием и репетицией миграции.
- Для доступа не с localhost необходим HTTPS, ограничения сети и политика доступа к главному административному ключу. Не публикуйте страницу наружу через открытый HTTP.
- Автоматические тесты и GitHub Actions проверяют серверные маршруты и сборку, но реальный визуальный прогон в Chrome на Windows необходим перед переносом в `main`.
