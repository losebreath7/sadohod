# Садоход

Единый репозиторий приложений покупателя и продавца и общего сервера.

Структура исходников после первого импорта: `server/`, `buyer_app/`, `seller_app/`, `shared/`, `tools/`.

Исходная версия для переноса: R8 / 0.8.4+27 с релизными «ВОРОТАМИ».

**Безопасность:** рабочие `.env`, пароли, токены, данные пользователей, резервные копии и Docker Volumes хранятся локально и не публикуются в Git.

Первый импорт исходников будет выполнен из проверенной локальной сборки; репозиторий пока содержит только первоначальные настройки.
